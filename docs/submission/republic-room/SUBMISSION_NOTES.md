# Submission Notes

## Project Title

The Republic Room: A Postmark 250 Puzzle Kiosk

## Short Description

A tiny retro point-and-click archive puzzle. Each run selects three Postmark 250 stamps. The player searches a room full of relics and decoys, matches the correct relics to the active stamps, and unlocks the Postmark 250 memory cabinet.

## Theme Connection

The Republic Room fits Theme 1: 8-Bit America because it turns America at 250 into a small retro museum-kiosk puzzle. Players interact with stamp-based American memory fragments as clickable relics in an old-screen archive room.

## What Was Built

- Static Republic Room route
- Title/start panel and how-to panel
- One-room clickable archive scene with polished wall, floor, desk, shelves, and cabinet staging
- Three active stamps per randomized run
- Ten visible room objects per run
- At least eight implemented stamp/relic pairs
- Decoy object pool
- Custom lightweight SVG artifact icons for relics and decoys
- Neutral inspect modal with object visual, clue text, and active stamp choices
- Correct-match seal progress with a cabinet object
- Gentle wrong-guess feedback with no penalty
- New Archive Request reset flow
- Final cabinet reveal linking back to Postmark 250
- Shared repo/assets are intentional; this puzzle has its own direct proof URL.

## What Remains Prototype

- Relic objects use custom lightweight SVG icons rather than full illustrated sprite art.
- No backend, database, analytics, login, or user submissions.
- No audio or persistent puzzle score is included.

## Proof / Scoring Notes

The Republic Room is a separate puzzle artifact, not a section of the collector sheet. It reuses Postmark 250 memory fragments as interactive relics while preserving the original gallery route as its own submission.
