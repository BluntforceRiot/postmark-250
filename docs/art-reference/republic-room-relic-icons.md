# Republic Room Relic Icons

These are custom lightweight SVG/pixel-style assets created for The Republic Room. They live in `public/assets/republic-room/relics/` and use the archive palette: parchment, navy, muted gold, copper, warm light, and dark outlines.

No external copyrighted assets were used.

## Implementation Note

The icons replace the earlier CSS/HTML prototype object symbols in the room and inspect modal. The room still uses large accessible hit buttons and tiny plaque labels, but the visual read now comes from artifact SVGs rather than debug-like placeholder shapes.
